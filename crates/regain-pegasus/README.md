# regain-pegasus

Rust drivers for Pegasus Astro FocusCube3 focusers and Falcon V2 rotators over
USB serial. Common bounded serial framing, separate device protocols. No vendor SDK or ASCOM needed.
See the [FocusCube3 protocol and setup guide](https://github.com/pulsarfab/regain/blob/main/docs/focuscube3.md).
[Experimental Falcon V2 support and validation status](https://github.com/pulsarfab/regain/blob/main/docs/falcon-v2.md).

Part of [PulsarFab regain](https://github.com/pulsarfab/regain). Apache-2.0.
This project is not affiliated with the hardware vendors it supports.
