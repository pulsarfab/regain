# regain-pegasus

Rust driver for the Pegasus Astro FocusCube3 focuser over USB serial: move,
halt, temperature, reverse, backlash and speed. No vendor SDK or ASCOM needed.
See the [protocol and setup guide](https://github.com/pulsarfab/regain/blob/main/docs/focuscube3.md).

Part of [PulsarFab regain](https://github.com/pulsarfab/regain). Apache-2.0.
This project is not affiliated with the hardware vendors it supports.
