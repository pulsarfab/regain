PulsarFab regain ASCOM installs four native camera entries, a CAA rotator, an EFW filter wheel, EAF and FocusCube3 focusers, an OFP2 cover/flat panel, and their local Rust workers. A standalone Alpaca server is also included.

For cameras connected to this PC, install the ZWO Windows camera driver from https://www.zwoastro.com/software/ first. CAA, EFW and EAF use the built-in Windows HID driver.

Close applications using these devices and stop this installation's PulsarFab regain Alpaca server before upgrading or uninstalling. Setup will not interrupt a running capture.

Device settings are kept when upgrading or uninstalling. No Windows service or firewall rule is added. Native COM drivers launch local USB workers and do not require an Alpaca server.

PulsarFab regain is independent software, not affiliated with or supported by ZWO.
