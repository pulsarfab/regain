ZWOgain ASCOM installs four camera entries, the Rust Alpaca server, and the SDK and direct USB workers.

For cameras connected to this PC, install the ZWO Windows camera driver from https://www.zwoastro.com/software/ first. It is not needed when connecting to an Alpaca server on another computer.

Close camera applications and stop this installation's ZWOgain Alpaca server before upgrading or uninstalling. Setup will not interrupt a running capture.

Camera settings are kept when upgrading or uninstalling. No Windows service or firewall rule is added. The COM driver starts the local server when needed.

ZWOgain is independent software, not affiliated with or supported by ZWO.
